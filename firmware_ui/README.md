## 页面使用

连接机械臂 Wi-Fi 后访问 `http://192.168.4.1/`。确认底座固定、运动范围清空，先检查每行角度，再解锁，从 0.5° 开始逐关节点动。

- 底座：关节 1 / 舵机 11。
- 肩：关节 2 / 舵机 12、13 联动。
- 肘：关节 3 / 舵机 14。
- 腕俯仰：关节 4 / 舵机 15。
- 腕旋转：关节 5 / 舵机 16。
- 夹爪 17 已拆除，页面禁用其控制。

v4 使用鼠标/触屏长按 ＋/− 调整单个关节，也支持按住空格/Enter。细调为每次0.25°、250ms最小间隔，常规为1.25°、250ms，快速为2°、200ms；还需加上 HTTP 请求耗时，因此1/5/10°每秒仅是理想上限，不是实际闭环速度保证。

调姿过程发送 `T:101` 有界绝对角度目标，不等待精确到位。每次只允许一个 HTTP 请求在途，不自动重试；持续按压时从最近目标累加，最多领先实测反馈4°。达到领先上限会暂缓增加，反馈跟上后在原按压期间继续。没有未执行的浏览器运动队列。

松手、移出按钮、pointercancel、丢失指针捕获、失焦、页面离开、速度切换、断线或反馈失效都会结束长按定时器；恢复连接/反馈后不自动恢复按压，需要重新按住。触屏按钮禁止滚动和长按菜单，按钮之外仍可滚动页面。松手只停止增加目标，最后已发送的目标可能继续执行最多4°，不等于硬件急停。

反馈延迟超过3秒时禁用调姿，超过10秒需重新启用。保护故障和 HTTP 确认失败会锁定。反馈仍用于实测角度显示、关节可用性及目标领先范围；不以0.3°到位误差作为全页面的操作门槛。角度遥测发送间隔250ms，实际取决于主循环和总线耗时。

手眼标定采样与调姿分开：松手后等机械臂稳定，再在 `tag_capture.py` 保存样本；`stationary_frame` 读取6组实际关节角，采样期间变化超过0.003rad则拒绝保存。目标角不能代替实际角。软件稳定性检查不是绝对精度证明。

新页面地址 `http://192.168.4.1/?v=4`，网页禁止缓存。肩关节驱动12和13，夹爪17仍禁用。初始化、零点、ID、运动学、串口协议及标定采集脚本均未改。

这是页面级约束，官方串口、ESP-NOW 等其他控制入口没有被禁用。调试时不要同时使用其他控制器。
